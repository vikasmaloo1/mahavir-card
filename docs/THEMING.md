# Storefront Theme

The customer storefront theme lives in `src/app/globals.css`.

Update the `--mc-*` variables in `:root` to change the visual identity:

- `--mc-surface`: application background
- `--mc-paper`: panel background
- `--mc-ink`: primary text and dark action color
- `--mc-muted`: secondary copy
- `--mc-accent`: primary action color
- `--mc-accent-soft`: selected and quiet action background
- `--mc-line`: borders and dividers

Use the `mc-*` classes for new storefront components. Legacy and admin screens retain their existing palette until deliberately redesigned.
