## 1. Business context
Mahavir Card is a **commercial offset printing press in Ahmedabad with 25+ years** of experience, serving businesses, agencies and trade printers across Gujarat and Rajasthan. The website now offers an online catalogue with live pricing (GST), spec configuration, CDR upload and ordering.

**What we print (verified against the website):** Visiting Card · Premium Card · Art Card · Letterhead/Envelope · Brochure · Leaflet · Sticker — plus **custom & bulk commercial printing** on request (the website is a selection, not the limit).

Real facts used across the content (from mahavircard.in): heavy **250–400 GSM** stocks; finishes incl. **thermal matt, spot-UV, gold foil, velvet, drip-off, corner cut**; **MOQ** — visiting cards from 1,000, premium from 500; **turnaround** — visiting cards 1–2 days, stationery/brochures 4–5 days, premium 7–10 days; **capacity 500–50,000+**; insured dispatch + counter pickup; 5-step order flow (choose → customise → upload CDR → confirm → print & dispatch).

## 2. Target audience
1. **Ahmedabad / Gujarat businesses** needing cards, stationery, brochures, stickers.
2. **Designers, agencies, resellers & small printers** who outsource production (B2B).
3. **Existing customers** reordering or exploring premium/custom work.

## 3. Visual identity
- **Aesthetic:** high-end print-catalogue / editorial — real product photography + confident typography + print-production motifs (crop marks, registration mark, CMYK colour bar). Not generic Canva, not "AI-graphic".
- **Palette:** deep navy ink `#0E1B2E`, warm ivory paper `#F1EADB`, muted slate blue, restrained **brass** accent for foil; CMYK dots only as micro-detail.
- **Type:** *Fraunces* (editorial display serif), *Archivo* (grotesque), *IBM Plex Mono* (technical labels/specs).
- **Logo:** the real Mahavir Card CMYK "M" mark is used as-is, small — never redesigned.
- **Rhythm:** layouts intentionally vary (full-bleed hero, type poster, split, product grid, macro, big-number, spec, website frame, contact) so the feed feels designed, not templated.

## 11. Editing the designs (source)
`_SOURCE/` holds the full, editable design system:
- `design-system.css` — tokens, fonts, layout styles.
- `content.mjs` — all copy/data for every asset (edit text here).
- `templates.mjs` — the layout functions.
- `build.mjs` — renderer (headless Chrome) that regenerates every PNG + the PDF and re-captures website screenshots.
- `html/` — the generated HTML for each asset (inspect/tweak).
- `assets/` — images referenced by the designs. `website-screens/` — captured site screenshots.

**Re-render everything:**
```bash
cd instagramcontent-emergent/_SOURCE
# one-time: a Chrome/Chromium binary + puppeteer-core are required
node build.mjs
```
Node dependencies are intentionally **not** committed. Install `puppeteer-core` and point `build.mjs` at your local Chrome to rebuild.
