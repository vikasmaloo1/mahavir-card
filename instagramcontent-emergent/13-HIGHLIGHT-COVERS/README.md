# 13 · Highlight Covers

Instagram Story-Highlight cover icons in the house style — brass line icons on deep navy, with a subtle CMYK dot row and a circle guide so they look right after Instagram crops them to a circle. Icon-only (the Highlight title supplies the word).

Order front-loads trust: **Printing** and **Work / Behind the Scenes** first (this is a real 25-year press), then the products, then Custom and Contact.

## Files & order (numbered = left-to-right order on the profile)
1. `1-printing.png` — **Printing**
2. `2-work.png` — **Work / Behind the Scenes**
3. `3-visiting-cards.png` — **Visiting Cards**
4. `4-premium-cards.png` — **Premium Cards**
5. `5-brochures.png` — **Brochures**
6. `6-stickers.png` — **Stickers**
7. `7-stationery.png` — **Stationery**
8. `8-custom.png` — **Custom**
9. `9-contact.png` — **Contact**

## How to set them
1. Save each PNG to your phone.
2. Create a Highlight → **Edit cover** → pick the matching numbered image.
3. Name the Highlight with the word above.
4. Instagram shows the newest Highlight first — create them in **reverse** (Contact first, Printing last) so they end up reading 1→9 left-to-right.

Add/edit icons or reorder in `_SOURCE/build-extra.mjs` (`ICONS` + `COVERS`) and re-run it.
