# Mahavir Card — Hashtag System

## How Instagram hashtags work now (verified, 2026)
Hashtags today are **content-classification signals, not reach engines**. What actually drives discovery:
- **Caption & on-screen keywords (Instagram SEO).** The search index reads your caption body, so the first line should contain plain keywords — e.g. *"commercial printing in Ahmedabad"*, *"visiting card printing"*.
- **A specific location tag** on every post (Khadia Golwad / Ahmedabad) plus **1–2 hyper-local hashtags**.
- **Reels metrics** — watch time, completion, shares — matter far more than tags.

### Rules we follow
1. **3–5 hashtags per feed post/carousel. 2–3 per Reel.** (Instagram effectively caps at 5.)
2. Prefer tags in the **~10K–500K posts** range. Skip mega-tags like `#love #instagood #printing` (too broad, suppresses reach).
3. **Rotate** between the sets below — reusing one identical block on every post can trip spam filters.
4. Always add the **Ahmedabad location** in the post location field (not just as a hashtag).
5. Before using a tag, **search it in Instagram**; if it says *"Recent posts hidden"* it's restricted — drop it.
6. Never buy tags, follow-for-follow, or use unrelated trending tags.
